## 기술 스택

| 항목 | 내용 |
|------|------|
| 엔진 | Unity 6 |
| 언어 | C# |
| 렌더링 | 2D Sprite, URP (2D Renderer), Shader Graph |
| 데이터 | ScriptableObject + JSON 직렬화 |
| UI | uGUI |
| 플랫폼 | Windows PC |

### 아키텍처 방향

- **도메인 분리** — 시뮬레이션 로직은 순수 C# 도메인 레이어(`MagicAcademy.Core`)로 구성하고, Unity 의존 코드는 프레젠테이션 레이어(`MagicAcademy.Presentation`)에 격리합니다. asmdef로 컴파일 단위를 분리해 도메인 로직의 유닛 테스트와 헤드리스 실행을 지원합니다.
- **데이터 정의와 런타임 상태 분리** — 학생·교사·수업·사건 등 정적 정의는 ScriptableObject로, 런타임 상태는 plain C# 객체로 관리합니다. 세이브/로드는 런타임 상태의 JSON 직렬화 한 단계로 처리합니다.
- **렌더링과 셰이더** — URP 2D Renderer 기반으로 시간대별 조명과 창문 연출을 다루고, 커스텀 셰이더는 Shader Graph로 프로토타이핑한 뒤 필요 시 HLSL을 직접 조정합니다.
- **헤드리스 밸런스 검증** — 도메인 레이어를 Unity 없이 실행 가능한 구조로 유지해, 자동 정책으로 다수 회차를 시뮬레이션하고 하루 일감 총량·자퇴율·재정 곡선 등을 데이터로 검증합니다.

## 게임 소개

Magic Academy는 폐교 위기의 마법학교를 맡은 교장이 되어 학생을 선발하고, 수업과 교사를 배정하며, 한정된 예산과 업무 시간 안에서 학교를 운영하는 데스크형 2D 경영 시뮬레이션입니다.

교장실을 찾아오는 학생, 교사, 졸업생, 상단, 마탑, 왕실 관계자와 대면하고 보고서와 요청을 검토합니다. 입학·교육·징계·계약·졸업에 관한 결정은 학생의 성장과 진로뿐 아니라 학교의 재정, 평판, 외부 조직과의 관계에도 장기적인 영향을 줍니다.

최종 목표는 각자의 가능성과 위험을 가진 학생을 끝까지 성장시켜 대마법사를 배출하고, 라이벌 학교를 넘어 명문 학교로 인정받는 것입니다.

---

## 핵심 특징

- **교장실 중심 운영** — 학교를 직접 돌아다니지 않고 방문자, 보고서, 장부, 시간표를 통해 전체 학교를 관리합니다.
- **학생 선발과 장기 육성** — 재능뿐 아니라 성향, 배경, 만족도, 관계와 비용을 함께 고려해 교육 경로를 설계합니다.
- **제한된 업무 시간** — 하루에 모든 요청을 처리할 수 없으며, 무엇을 승인하고 보류할지 결정해야 합니다.
- **선택형 사건 시스템** — 학생·교사·조직 간 관계와 과거 결정에 따라 사건의 조건과 결과가 달라집니다.
- **교사와 수업 배정** — 교사의 전문 분야와 교육 철학, 학생과의 궁합, 재료 비용을 고려해 수업을 구성합니다.
- **졸업 이후의 결과** — 졸업생은 왕실 마법사, 연구자, 모험가, 상인, 교수 등으로 활동하며 학교에 새로운 사건과 보상을 돌려줍니다.
- **외부 조직과 라이벌 학교** — 상단, 마탑, 왕실과 계약하고 학생·교사·재료·공인을 두고 라이벌 학교와 경쟁합니다.

---

## 핵심 게임 루프

1. **아침 보고서 확인** — 학생 성장, 수업 결과, 사건, 수입과 지출을 확인합니다.
2. **방문자 및 문서 처리** — 입학 지원자, 교사, 졸업생, 외부 조직의 요청을 검토합니다.
3. **운영 결정** — 수업 배정, 예산 조정, 재료 구매, 연구 투자, 계약과 징계를 결정합니다.
4. **사감 지정** — 교사 또는 교장을 야간 당직에 배치하거나 위험을 감수합니다.
5. **하루 종료 정산** — 성장, 피로, 관계, 재정, 사건과 평판 변화를 계산합니다.
6. **학기 평가** — 진급, 유급, 자퇴, 졸업과 외부 조직의 평가를 처리합니다.

## 주요 자원

| 자원 | 역할 |
|------|------|
| 골드 | 교사 급여, 재료 구매, 장학금, 시설 개선, 사고 보상 |
| 평판 | 지원자·거래처의 질, 외부 의뢰, 학교 공인과 명문도 |
| 마법 재료 | 실습 수업, 연구, 졸업 작품, 고급 교육 과정 |
| 업무 시간 | 하루에 처리 가능한 면담·검토·배정 횟수 제한 |
| 통찰 포인트 | 졸업생과 대마법사 배출로 획득, 교장 능력 성장에 사용 |

## 개발 로드맵

| Phase | 상태 | 내용 |
|-------|------|------|
| 0. 프로젝트 셋업 | ✅ 진행 완료 | Unity 프로젝트 구조, asmdef 분리, GitHub 규칙 |
| 1. 하루 루프 FSM | 🚧 진행 중 | 3페이즈 상태머신, 행동력 6 소비 구조 |
| 2. 학생 데이터 + 입학 심사 | ⏳ 예정 | 학생 SO 10종, UI 아키텍처 확정 |
| 3. 수업 배정 + 주간 성장 | ⏳ 예정 | 효율 공식, 등급 표시 |
| 4. 문서함·방문자·미처리 페널티 | ⏳ 예정 | 행동력 경제, 하루 종료 정산 |
| 5. 사건 시스템 + 사감 | ⏳ 예정 | 성향·관계 기반 사건, 야간 판정 |
| 6. 졸업 → 졸업생 결과 → 통찰 포인트 | ⏳ 예정 | 최우선 검증 루프 완성 |
| 7. 경제 연결 (골드·평판·재료·계약) | ⏳ 예정 | 상단 계약과 재정 순환 |
| 8. 확장 (마탑·왕실·라이벌·시설) | ⏳ 예정 | 후반 압박 곡선과 캠페인 목표 |

**최우선 검증 루프**: 입학 → 수업 배정 → 사건 발생 → 졸업 결정 → 졸업생 결과
